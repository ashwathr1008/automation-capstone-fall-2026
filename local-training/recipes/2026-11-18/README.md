# Original LanM training recipe

This directory preserves the exact source and compact provenance used for the completed 18 November 2026 training runs. The manifest records original source paths and SHA-256 values. These files are audit snapshots, not an alternate runnable installation: their original directory assumptions remain intact.

The active utilities two directories above add portable profile setup, pinned provisioning and explicit GPU handoff. Use their README for a fresh clone. No weights, raw training records, private database, account credentials or personal workstation directory is included here.

The original narrative README is represented by its hash rather than its personal directory example. The training source, dependency lock, model/data identities, completed metrics and artifact hashes remain preserved.
